# Cheridose social covers

These exports use the same Terceira map, route line, compass, warm ivory, teal,
apricot, and official Cheridose SVG icon as the website. They intentionally omit
campaign copy so they remain useful as quiet, crop-safe page backgrounds.

| File                           |      Canvas | Intended use                        |
| ------------------------------ | ----------: | ----------------------------------- |
| `facebook-page-cover.png`      |  1640 × 624 | Cream Facebook Page cover           |
| `facebook-profile-picture.png` | 1024 × 1024 | Facebook profile image; circle-safe |
| `x-profile-header.png`         |  1500 × 500 | Cream X profile header              |
| `linkedin-page-cover.png`      |  1512 × 256 | Cream LinkedIn company Page cover   |
| `youtube-channel-banner.png`   | 2560 × 1440 | Cream YouTube channel banner        |
| `social-cover-preview.png`     | 1200 × 1992 | Contact sheet for review only       |

Each cover also has a deep-teal alternate using the same filename with `-teal`
before `.png`, such as `facebook-page-cover-teal.png`.

The primary island and route remain near the center so they tolerate responsive
cropping. The YouTube artwork keeps its icon and attribution within the central
all-device safe area. X attribution stays clear of its typical top and bottom
crop.

The Facebook profile image uses the official icon in high-contrast ivory and
apricot on solid teal. Its generous inset keeps the complete mark clear after
Facebook applies a circular crop and when the image is displayed very small.

Map data © OpenStreetMap contributors. Keep the attribution visible when using
or adapting these files.
